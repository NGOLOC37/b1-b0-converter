# RF B1 → B0 Converter

[![Deploy to GitHub Pages](https://github.com/NGOLOC37/b1-b0-converter/actions/workflows/pages.yml/badge.svg)](https://github.com/NGOLOC37/b1-b0-converter/actions/workflows/pages.yml)

## 🌐 Truy cập trang web

**https://ngoloc37.github.io/b1-b0-converter/**

Công cụ chuyển đổi mã RF từ định dạng **B1** (Tasmota RF Bridge `RfRaw 177`) sang **B0** để phát lại.

## Cách dùng

1. Mở link ở trên
2. Dán chuỗi B1 nhận được từ Tasmota (vd: `AA B1 05 05CE 29D5 0A0B 1ABA 29D7 C09293 55`)
3. Bấm **Convert** và copy kết quả B0
